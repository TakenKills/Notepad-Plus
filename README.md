# Notepad Plus

## This is a simple notepad organizer app.

<br>
<br>

<h1 align="center">Notepad Plus ( Python ) </h1>

If you've ever used notepads, you know that they're pretty useful in terms of taking notes.
But you also would know that notepads are pretty frustrating to organize.

So... I made something along the lines of a "notepad organizer" in python.

<blockquote><em>Note: This isn’t production-grade code, so there’s plenty of room for optimization and improvement.</em></blockquote>

## Installation

You can fork the repository, and compile main.py using python.

## Features

Everything is pretty self-explanatory when it comes to this app.

- You can import an existing notepad into the app. (Only .txt supported)
- You can create and delete files within the app making it easy to organize your files. (creates ".txt" files)
- There is a text editor that you can use to make edits to the files.
- There is a password system inplace to protect your files.
- You can rename files.
